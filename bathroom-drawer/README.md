# Bathroom Drawer — Gridfinity Organization Project

Goal: organize one bathroom drawer (toothbrush, toothpaste, shaving/razor,
floss, small items) using the **Gridfinity (42mm)** system generated by
`../gridfinity.scad`. Printer: **Bambu Lab P2S (256×256mm bed)**.

> This is a *real* organization project — not the OpenGrid (28mm) under-desk
> work elsewhere in this repo. Different system entirely.

## Decisions locked in

| Choice | Value |
|---|---|
| System | Gridfinity, 42mm grid, 7mm height units |
| Printer / bed | Bambu P2S, 256×256mm → up to **6×6 cells (252mm)** per baseplate tile |
| Baseplate style | Plain / lite (gravity-held, fastest to print) |
| Contents | Toothbrush, toothpaste, shaving/razor, floss, small items |

## Plan

**Step 1 — tolerance test (DO THIS FIRST).** ✅ files generated
Print these three and check the bin *feet click into the baseplate* with a
light, satisfying snugness (not loose, not forced):
- `stl/TEST_baseplate_2x2.stl`
- `stl/TEST_bin_1x1x3.stl`
- `stl/TEST_bin_2x1x3.stl`

If the fit is too tight or too loose, we nudge one tolerance number in
`gridfinity.scad` (`CLEAR`, currently 0.25mm/side) and reprint just the test.
Getting this right ONCE means every later part fits. ~30 min of printing.

**Step 2 — measure the drawer.** ⬅ NEEDED FROM JOHN
Interior **Width × Depth × usable Height** in mm (see README question).

**Step 3 — compute the grid & generate the full set.** ⬜ blocked on Step 2
- Fit an N×M grid of 42mm cells inside the drawer floor.
- Split the baseplate into P2S-printable tiles (≤6×6 cells each).
- Generate the curated bathroom bin lineup (below), all standard modules that
  drop into any tile.

## Proposed bin lineup (draft — finalized after measuring)

| Item | Bin | Notes |
|---|---|---|
| Toothbrushes | 1×N long bin | N chosen so brushes lie flat along it |
| Toothpaste / tubes | 1×2 or 1×3 | lies flat |
| Razor + shaving | 2×2 | bulkier head clearance |
| Floss / clippers / tweezers | 1×1 ×2–3 | small items |
| Cotton swabs / pads | 2×2 taller (5–6u) | upright-ish |

## Future refinements (not in v1 generator yet)

- Finger scoops (angled floor ramp to sweep small items out)
- Label tabs (front-edge tab for labeling)

These are nice-to-haves; the current bins + baseplate are fully functional
without them. Easy to add once the base layout is confirmed.
